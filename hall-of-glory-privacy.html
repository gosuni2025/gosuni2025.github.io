공개 웹 테스트 기준

현재 공개 웹은 기본 게임을 기기에 저장하고 PvP만 서버에 연결합니다. 이전 온라인 게임 계정과 서버 자료도 아래 삭제 절차의 대상입니다. 온라인 계정 삭제는 앱 설치 없이 웹 계정 관리에서 본인 확인 후 이용할 수 있습니다.

적용 버전처리 정보로그인외부 서비스기기 저장계정 삭제남는 기록·백업권리·문의

1. 적용 범위와 버전

현재 공개 웹 테스트는 기본 모험·성장·장비·기록을 로그인 없이 기기에 저장하고 PvP에서 서버에 연결합니다. 서버는 온라인 계정·참가 구성·랭킹·전투 결과를 본인 확인, PvP 제공과 보안에 사용합니다.

이전 온라인 게임의 서버 모험단·동료·장비·재화·진행·전투·게시·거래·재시도 기록은 별도로 남아 있을 수 있으며, 소유권 확인 후 계정 삭제 절차로 처리합니다. 이전 서버 진행의 자동 이전이나 기기 간 동기화는 제공하지 않습니다. 모바일 앱의 스토어 출시는 준비 중입니다.

Hall of Glory 소스에는 광고 SDK나 Firebase Analytics를 추가하지 않았습니다. 다만 공개 게임 호스팅에서 Cloudflare 경량 웹 분석 스크립트가 자동 주입되는 것을 관측했습니다. 호스팅 분석은 아래 외부 서비스 안내를 확인해 주세요. 이 전용 소개·개인정보 페이지 소스에도 광고·분석 스크립트를 추가하지 않았습니다. 다른 서비스의 기능은 Gosuni2025 공통 개인정보 처리방침을 확인해 주세요.

2. 처리하는 정보와 목적

기기 저장과 온라인 계정의 처리 구분
정보처리 위치와 목적
기본 게임 진행기본 게임에서는 모험단·동료 이름, 능력치·장비·스킬·아이템·재화, 진행·전투 기록과 로컬 모험 일지를 기기에서 처리합니다. 기본 플레이를 위해 이 저장 전체를 게임 서버에 업로드하지 않습니다.
PvP 참가 정보PvP를 선택하면 모험단 이름과 참가 동료의 식별자·이름·직업·성별·성장 수치·능력치·장비·스킬·행동 설정, 게임 규칙 버전을 서버에 보냅니다. 서버는 구성을 검증하고 PvP 파티·랭킹·전투 결과와 재시도 기록을 저장합니다. 로컬 재화·소지품 전체나 로컬 저장 전체를 보내는 방식은 아닙니다.
인증 계정·연결Firebase와 선택한 Google·Apple 제공자가 계정 식별자, 이메일·이름 등 프로필과 인증 정보를 처리합니다. 게임 서버는 검증한 Firebase 프로젝트·사용자 식별자(UID)와 온라인 게임 계정의 연결 정보를 저장합니다. 이 식별 정보는 익명 정보가 아닙니다.
로그인 상태Firebase ID 토큰을 서버 검증에 사용하고 별도의 게임 세션을 발급합니다. 서버는 서명·유효성·사용자 상태와 인증 시각을 확인합니다. 게임 세션과 필요한 검증 정보는 로그인 보호에 사용합니다.
이전 서버 자료기존 게임 ID·비밀번호 검증값, 서버 모험단·동료·재화·소지품·진행·설정, 전투·랭킹·거래·게시 자료와 재시도 기록이 있을 수 있습니다. 기존 계정 로그인·연결·복구·삭제 시 소유권을 확인합니다.
삭제 진행 정보삭제 작업 중에는 처리에 필요한 계정 ID·프로젝트·UID와 단계 정보를 별도 제한된 원장에서 관리합니다. 해당 정리가 끝나면 원래 식별자를 제거하고 최소한의 삭제 예약·진행·재시도 확인 기록을 남깁니다. 자세한 범위는 아래에 설명합니다.
문의·접속 정보문의한 이메일과 본문은 확인·답변에 사용합니다. 운영 환경과 호스팅·인증 서비스는 서비스 전달·보안을 위해 요청·응답, IP 주소와 브라우저·기기 등 접속 정보를 처리할 수 있습니다.

PvP 모험단·동료 이름과 랭킹·전투 표시 정보, 이전 서버의 공개 게시·거래 정보는 해당 화면에서 다른 이용자에게 보일 수 있습니다. 이름이나 게시글에 공개할 필요가 없는 실명·연락처를 넣지 않도록 주의해 주세요.

3. 로그인 정보의 처리

Google·Apple 로그인은 선택한 제공자와 Firebase가 인증을 처리하고, 이메일 비밀번호 로그인은 Firebase Authentication이 처리합니다. 이메일·프로필 이름은 제공자나 Firebase가 처리하거나 검증용 토큰에 포함할 수 있습니다. 게임 서버는 이메일이나 제공자 프로필 이름을 별도 게임 프로필에 복사하지 않으며, 이메일이 같다는 이유로 기존 모험단을 자동으로 합치지 않습니다. 검증한 프로젝트·UID와 명시적인 신규 생성 또는 기존 계정 소유권 확인을 연결 기준으로 사용합니다.

Firebase 방식의 비밀번호 원문·검증값은 게임 서버에 저장하지 않습니다. Google·Apple의 비밀번호나 제공자 액세스 토큰을 게임 로그인 정보로 보내도록 요구하지 않습니다. Firebase ID 토큰은 로그인·재인증 검증에 사용하며 원문을 게임 데이터베이스에 저장하지 않습니다. Apple 연결을 철회할 때 필요한 제공자 증명은 인증 SDK의 철회 절차에 사용합니다.

로그아웃은 게임 세션을 끝내는 동작입니다. 로컬 진행, 온라인 계정이나 Firebase 인증 계정을 삭제하는 동작과는 다릅니다.

4. 외부 서비스

외부 인증·호스팅 제공자는 여러 국가의 기반 시설에서 정보를 처리할 수 있습니다. 서비스별 처리 범위는 위 개인정보처리방침을 함께 확인해 주세요. 특정 국가에만 저장되거나 국외 처리가 없다고 보장하지 않습니다.

5. 기기 저장과 로컬 진행 초기화

공개 웹의 기본 게임은 IndexedDB에 기본 게임 진행을 저장합니다. 앱에서도 해당 기기의 저장 공간을 사용합니다. 음량 등 기기 설정과 삭제 진행 상태를 다시 조회할 무작위 티켓은 별도 기기 저장소에 남을 수 있습니다. 삭제 티켓은 계정·비밀번호·인증 토큰을 저장하는 용도가 아니며, 다른 사람에게 공유하지 마세요.

공개 웹의 로컬 게임 → 이 기기의 로컬 진행 초기화는 기기에 저장한 모험단·동료·재화·기록을 지우는 동작입니다. 온라인 PvP 계정과 Firebase 계정은 유지됩니다. 반대로 온라인 계정을 삭제해도 로컬 진행은 자동으로 지우지 않습니다. 브라우저의 사이트 데이터 삭제나 앱 데이터 삭제·제거 또한 서버 계정 삭제 요청을 대신하지 않습니다.

웹 온라인 세션에는 쿠키를 사용하며, 앱의 게임 세션은 메모리에서 관리합니다. Firebase 웹 인증은 메모리에 두도록 설정하고 네이티브 소셜 인증 SDK 상태도 인증 작업 뒤 정리합니다. 영구 삭제에서는 본인 확인부터 클라우드 삭제까지 필요한 동안만 삭제 전용 인증을 유지한 뒤 정리합니다. 제공자 앱·브라우저 자체의 로그인 상태는 해당 제공자가 관리합니다.

6. 온라인 계정 영구 삭제와 진행 재개

앱 설치 없이 온라인 계정 삭제

Hall of Glory 온라인 계정 관리에서 삭제할 계정으로 본인 확인한 뒤 DELETE를 입력하세요. 로컬 모험단 생성이나 PvP 참가 없이 이용할 수 있습니다. 진행 티켓이 남아 있으면 같은 화면에서 상태를 확인할 수 있습니다.

Firebase 연결 계정은 같은 Google·Apple 계정 또는 이메일의 최근 비밀번호 확인을 거쳐 DELETE를 입력합니다. 기존 비밀번호 방식 계정은 게임 ID와 현재 비밀번호로 확인합니다. 보관 중인 서버 계정도 소유권을 직접 확인하며, 복구나 새 모험단 생성을 먼저 요구하지 않습니다. Firebase 인증만 만들고 게임 계정 생성을 취소한 경우도 같은 본인 확인으로 삭제할 수 있습니다.

서버가 삭제 요청과 처리 티켓을 접수한 뒤 게임 데이터·자격 증명·세션을 정리하고, Firebase 연결 계정은 인증 SDK로 삭제합니다. Apple 연결이 있으면 같은 Apple 계정으로 연결 철회 절차를 먼저 수행합니다. 서버가 Firebase 사용자의 부재를 확인한 뒤 온라인 계정 삭제 완료를 표시합니다. Google·Apple 자체 계정은 삭제하지 않습니다.

삭제를 접수했지만 서버 자료 정리, 클라우드 계정 삭제 또는 최종 확인이 남으면 진행 중으로 표시합니다. 연결 실패·앱 종료 등이 생기면 같은 기기의 저장된 삭제 진행 상태 확인을 사용하세요. 연결 계정이 아직 존재하면 같은 계정으로 다시 본인 확인하여 미완료 삭제를 이어갈 수 있습니다. 이미 삭제한 계정의 완료 확인을 위해 소셜 로그인을 다시 열 필요는 없습니다.

미정산 거래 의무가 있거나 과거 공유 기록의 소유권을 확실히 분류하지 못한 경우 자동 삭제를 완료했다고 표시하지 않고 정산 또는 별도 검토를 안내합니다. 문의 접수나 오류 응답을 삭제 완료로 취급하지 않습니다.

휴지통 보관은 영구 삭제가 아닙니다.

기존 서버 모험단의 휴지통 보관은 동료·소지품 등을 복구할 수 있도록 보관하는 별도 기능입니다. 보관·로그아웃만으로 Firebase 계정이나 서버 개인정보 전체가 삭제되는 것은 아닙니다.

7. 삭제 뒤 남는 최소 기록과 이전 원본·백업

계정 자료는 서비스 이용과 복구를 위해 보관하다가 영구 삭제 요청을 처리합니다. 삭제 후에는 과거 백업 복원이나 요청 재전송으로 계정이 되살아나지 않도록 최소 원장을 유지합니다. 원장 예약은 이전 자료가 재수입될 가능성이 남아 있는 동안 보관합니다. 원래 계정 ID·UID·티켓 대신 비밀 키로 만든 HMAC 식별 태그와 진행·확인 정보를 남깁니다. 이 태그를 익명화된 데이터라고 단정하지 않습니다. 미완료 작업에는 해당 정리가 끝날 때까지 필요한 계정 ID나 프로젝트·UID가 남을 수 있으며, 원래 식별자는 각 정리가 끝난 뒤 원장에서 제거합니다.

삭제 원장은 게임·인증 백업과 분리하고 접근을 제한합니다. 지원하는 복원 절차는 현재 삭제 원장과 대조하여 삭제된 계정·소유 자료·비밀번호 검증값이 다시 사용되지 않도록 처리합니다. 원장을 게임의 과거 백업으로 함께 되돌리는 절차는 지원하지 않습니다.

기존 백업에는 과거 자료가 남아 있을 수 있습니다. 앱 자체의 백업 자동 만료 기능은 아직 없으며 접근을 제한해 복구·검증에만 사용합니다. 현재 삭제 원장과 대조하지 않은 복원은 지원하지 않습니다. 온라인 삭제 완료는 라이브 서버·인증 자료의 정리이며 모든 오프라인 복제본의 즉시 물리 파기를 뜻하지 않습니다. 백업 정리 관련 요청도 아래 연락처로 문의할 수 있습니다. 정식 출시 전 보존·파기 기준을 확정해 갱신합니다. 기존 운영 게임의 불변 이관 원본은 이 공개 테스트에 가져오지 않았습니다.
