Gosuni2025 Services

개인정보 처리방침

시행일: 2026년 10월 20일

고순이2025(이하 "회사")는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 이와 관련한 고충을 신속하게 처리하기 위하여 다음과 같이 개인정보 처리방침을 수립·공개합니다.

1. 수집하는 개인정보 항목

서비스별 저장 방식

Gosuni2025의 앱과 게임은 서비스 성격에 따라 로컬 저장 또는 온라인 기능용 서버 저장 방식을 사용합니다.

서비스 제공, 광고 표시, 사용성 개선, 온라인 플레이 제공을 위해 서비스별로 아래 정보가 처리될 수 있습니다:

온라인 게임 서비스 (대국전열: 오토 배틀러)

  • 게스트 플레이어 ID, 선택적으로 연결한 계정 ID
  • 비밀번호 원문이 아닌 비밀번호 검증용 해시와 솔트
  • 로그인 토큰의 해시, 세션 생성 및 마지막 사용 시각
  • 프로필 이름, 프로필 아이콘, 덱 및 진형 스냅샷
  • 비동기 상대 매칭, 전투 결과, 순위 및 플레이 기록
  • 서버 요청 처리 과정에서 발생하는 IP 주소, 기기 및 네트워크 정보

광고 서비스 (Unity Ads)

  • 기기 정보 (모델명, OS 버전)
  • 광고 식별자 (GAID/IDFA)
  • IP 주소 (대략적 위치 추정용)
  • 광고 시청 기록

광고 서비스 (Google AdMob)

  • 기기 정보 (모델명, OS 버전)
  • 광고 식별자 (GAID/IDFA)
  • IP 주소 (대략적 위치 추정용)
  • 광고 상호작용 데이터

분석 서비스 (Firebase Analytics)

  • 기기 정보 (모델명, OS 버전)
  • 앱 사용 통계 (세션, 이벤트)
  • 대략적 위치 (IP 기반)

플레이 통계 (Gosuni2025 자체 분석 서버)

외부 분석 SDK 아님 · 광고·추적(ATT) 목적 아님 · 옵션에서 끌 수 있음

아래 표의 게임 빌드는 게임 개선을 위해 플레이 통계를 개발자가 직접 운영하는 분석 서버(Cloudflare Workers·D1)로 자동 전송합니다. 외부 분석 SDK를 사용하지 않으며, 광고나 앱 간 추적에 이용하지 않습니다. 이 기능은 게임 옵션의 "플레이 통계 보내기"로 켜고 끌 수 있으며 처음에는 켜져 있습니다.

  • 게임이 처음 실행될 때 만드는 무작위 설치 ID (광고 식별자·기기 고유 ID·계정과 연결하지 않음)
  • 세션 시작·종료 시각과 플레이 시간, 첫 실행, 앱의 백그라운드 전환
  • 게임 화면 이동 기록
  • 게임 진행 기록 (런·스테이지·전투 등의 시작·완료·실패·포기)
  • 게임 내 선택 기록 (보상 선택, 상점 구매 등)
  • 게임 빌드 버전, 플랫폼(OS 종류), OS 버전, 언어 설정, 배포 채널

광고 식별자(GAID/IDFA), 기기 고유 ID, 이름, 이메일, 이용자가 직접 입력한 문장은 수집하지 않으며, 분석 서버는 IP 주소와 User-Agent를 저장하지 않습니다. 전송 전의 통계는 기기의 앱 저장 공간(게임 세이브와 별도)에 잠시 보관되며, 30일 안에 전송되지 않으면 보내지 않고 삭제됩니다.

Solitaire Masquerade

계정 없음 · 광고·외부 분석 SDK 없음 · 추적(ATT) 없음

Solitaire Masquerade는 회원 계정을 만들지 않으며, 광고 SDK와 외부 분석 SDK를 사용하지 않고, 앱 추적 투명성(ATT) 권한을 요청하거나 이용자를 추적하지 않습니다. 게임 진행 상황과 설정은 이용자의 기기에만 저장됩니다.

웹(itch.io)과 Windows(STOVE·Epic Games Store) 빌드는 플레이 통계를 개발자의 분석 서버로 자동 전송하며, 옵션의 "익명 플레이 통계 보내기"로 끌 수 있습니다. Google Play·원스토어 등 모바일 스토어 빌드는 플레이 통계를 보내지 않습니다.

이용자가 옵션 화면에서 직접 "성능 보고서 전송"을 누른 경우에만 아래의 익명 성능 정보가 개발자의 성능 분석 서버(Cloudflare Workers)로 전송됩니다. 이름, 이메일, 광고 식별자 등 이용자를 식별할 수 있는 정보는 포함하지 않습니다.

3. 개인정보 보유 및 이용 기간

로컬 저장형 앱의 데이터는 주로 사용자 기기에 저장됩니다. 온라인 기능이 있는 앱의 서버 데이터는 서비스 제공 기간 동안 보관하며, 앱 내 삭제 기능 또는 고객센터 요청을 통해 삭제할 수 있습니다.

Solitaire Masquerade의 성능 보고서는 성능 분석에 필요한 기간 동안만 보관하며, 분석 목적 달성 후 지체 없이 파기합니다.

Neon Logic의 웹 체험판 성능 보고서는 성능 분석에 필요한 기간 동안만 보관하며, 분석 목적 달성 후 지체 없이 파기합니다. 스토어 빌드는 보고서를 전송하지 않습니다.

플레이 통계의 개별 이벤트 기록은 수신 후 최대 90일 동안 보관한 뒤 삭제합니다. 일별 집계와 설치 ID별 요약(첫·마지막 접속일, 접속한 날짜, 마지막 화면·진행 위치)은 기간 제한 없이 보관합니다. 게임 옵션에서 플레이 통계 전송을 끄면 기기에 저장된 설치 ID와 아직 보내지 않은 통계가 즉시 삭제됩니다.

제3자 서비스의 보유 기간은 각 서비스의 정책을 따릅니다:

  • Unity 개인정보 처리방침
  • Google/Firebase/AdMob 개인정보 처리방침
  • Cloudflare 개인정보 처리방침
